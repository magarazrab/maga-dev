---

# 💡 Сцена 2 — Что такое база данных?

> Нам нужно место, где приложение сможет хранить информацию.
>
> Такое место называется **база данных**.

Простое объяснение:

> Представьте обычную тетрадь.
>
> Вы записали туда:
>
> «Выучить Python».
>
> Закрыли тетрадь.
>
> На следующий день открыли её — запись осталась.
>
> База данных работает примерно по такому принципу, только компьютер делает всё это автоматически.

Показываешь:

```text
Приложение
     ↓
База данных
     ↓
Сохранённые данные
```

---

# 🧠 Сцена 3 — Что именно будем сохранять?

> В нашем приложении нам не нужно сохранять всё подряд.
>
> Нам нужны только задачи пользователя.

Например:

```text
ID: 1
Задача: Выучить Python
Статус: Не выполнена
```

И ещё:

```text
ID: 2
Задача: Посмотреть урок
Статус: Выполнена
```

> Таким образом база данных будет знать, какие задачи существуют и выполнены они или нет.

---

# 🐍 Сцена 4 — Выбираем простую базу данных

> Для первого проекта нам не нужна сложная база данных.
>
> Мы возьмём **SQLite**.
>
> Почему именно её?
>
> Потому что она очень простая для обучения.
>
> Она хранит данные в одном файле и отлично подходит для нашего первого проекта.

Показываешь:

```text
ai-study-assistant/
│
├── index.html
├── style.css
├── script.js
├── app.py
└── database.db
```

> Вот этот файл `database.db` и будет хранить наши данные.

---

# 🤖 Сцена 5 — Просим ИИ создать базу

> Но опять же — мы не будем писать всё вручную.
>
> Давайте попросим ИИ.

Промт:

```text
У меня есть учебное приложение AI Study Assistant
на HTML, CSS, JavaScript и Python Flask.

Добавь SQLite для хранения задач.

Нужно:
- создать базу данных;
- создать таблицу tasks;
- хранить id задачи;
- хранить текст задачи;
- хранить статус выполнена/не выполнена;
- сохранять новые задачи;
- получать задачи из базы.

Используй максимально простой код.
Объясни каждую часть простыми словами.

Не ломай существующий проект.
```

> ИИ создаёт необходимые изменения.

# ⚙️ Сцена 7 — Создаём таблицу

> Теперь объясним ещё одно простое понятие — **таблица**.

| -- | --------------- | --------- |

# 🐛 Сцена 11 — Что делать, если данные не сохраняются?

> Конечно, может появиться ошибка.
>
> Например, задача появляется, но после перезапуска исчезает.

> Не паникуем.

> Показываем ИИ наш код и объясняем проблему.

Промт:

```text
Моё приложение использует Flask и SQLite.

Проблема:
задачи отображаются во время работы,
но после перезапуска приложения исчезают.

Проанализируй код.

Объясни:
1. Почему данные не сохраняются?
2. В каком файле проблема?
3. Что нужно изменить?
4. Как правильно проверить исправление?

Не переписывай проект полностью.
```

> ИИ анализирует проблему.

> Исправляем.

> Снова тестируем.
